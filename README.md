# Mekan Bul 📍

Mekan Bul is a mobile application developed with Flutter that helps users discover restaurants and entertainment venues based on their age, preferences, and location.

The app aims to provide a personalized and user-friendly experience for finding the most suitable places nearby.

---

## 🚀 Features

- User registration and login system  
- Age and preference-based venue recommendations  
- Restaurant & entertainment venue listing  
- Detailed venue pages  
- User reviews and ratings  
- Favorites system  
- Map integration for location viewing  

---

## 🛠 Technologies Used

- Flutter  
- Dart  
- SQLite  
- Provider (State Management)  
- Google Maps API
